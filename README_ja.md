# コンパクトなスピン三次元多様体で Nieh–Yan 電荷の符号を読む

Muacca · DPPUv8 Paper 08 · **v1** · 初版 2026-11-22

## 要旨

一様な動的 Nieh–Yan 場の保存電荷は、プローブの空間 Dirac 作用素に一定のシフトを与える。本稿では、正負の電荷が異なる絶対値で初めて核を生じるのはどのような場合かを問う。ファイバーの面積を1とした基準 Sol トーラス束に不変標構のスピン構造を取り、非零のファイバー運動量に制限する。このとき正負の第一閾値が分裂するための必要十分条件は、整数係数の不定値二元二次形式の最小正値と、負の値の最小絶対値が異なることである。証明には、実直線上の二成分作用素の基底状態の正値性と、それに対応する符号付き固有値の絶対値の狭義単調性を用いる。正のトレースが60以下の原始モノドロミー共役類をすべて調べると、488類のうち472類で閾値が分裂し、そのうち6類では通常の η 不変量が零になる。

さらに平坦幾何、球面幾何、Nil 幾何および積幾何の商を用い、手性、η 不変量、閾値の分裂を区別する具体例を示す。最後に、コンパクトな Nil 宇宙で質量をもつ Dirac 場の一つの殻を対象とする、時間依存の測定を与える。両方の電荷枝で始端と終端それぞれに共通の Levi–Civita 射影を用いると、1コピー当たりの粒子の平均占有数は負電荷で約 $`0.168451`$ 、正電荷で約 $`0.042475`$ となる。こうして符号を区別できるかどうかは、プローブ、その準備、計量および測定に依存する。
